# ⚡ AI Discovery Engine – Enterprise E-Commerce Platform

An enterprise-grade, AI-powered e-commerce product discovery and personalization platform built with **React, Vite, Express, Prisma ORM, and Google Gemini 1.5 Flash AI**.

The AI Discovery Engine transforms traditional keyword-based search into a real-time, intent-aware shopping experience comparable to Amazon, Flipkart, or Myntra.

---

## 🌟 Key Features & AI Architecture

### 1. 🧠 Real-Time Intent Detection Engine
- Evaluates search terms, page view durations (`viewDurationSec`), cart items, wishlist saves, and budget caps in real-time.
- Classifies user intent into 8 dynamic profiles: `Gaming Setup`, `Office Setup`, `Photography`, `Fitness`, `Budget Shopping`, `Premium Buyer`, `Smart Home`, `Audio Enthusiast`.
- Features a **Cold Start Fallback Guarantee**: Feeds for unauthenticated or new users seamlessly transition to trending and top-rated catalog items — **recommendation feeds are never empty**.

### 2. 🛒 Smart Shopping Experience & Ecosystem Bundles
- **Frequently Bought Together**: Amazon-style bundle widget with interactive checkboxes, discount pricing, and 1-click cart addition.
- **Complete The Look / Smart Bundles**: Curated 4-piece ecosystem package showcase with package discount savings pills (`Save 10% on Bundle`).
- **AI Confidence Score Meters**: Glowing visual progress bars displaying **Confidence %**, **Similarity Score**, and **Category Match Score**.
- **Explainable Recommendation Cards**: Natural language justification chips generated by Gemini API (`💡 Matches your current search for high-performance gaming laptops`).

### 3. 📊 Enterprise Analytics & Monitoring Dashboard
- **Search Analytics**: Top searched keywords horizontal bar chart, zero-result search inventory alerts, search conversion rate %, AI usage %, and response latency (142 ms).
- **Customer Journey Funnel**: Full 6-stage conversion funnel (`Home → Search → Product View → Wishlist → Cart → Purchase`), step-by-step drop-off analysis, session duration, and top customer paths.
- **Recommendation Feedback Loop**: Real-time event tracking for `shown`, `clicked`, `carted`, `purchased`, `ignored` events, calculating CTR % and conversion rates per recommendation engine type.

## 🚀 Quick Start & Local Setup Guide

### 1. Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### 2. Backend Setup & Database Seeding
```bash
# Navigate to backend directory
cd backend

# Install dependencies
npm install

# Push database schema & generate Prisma Client
npx prisma db push

# Seed the database with 26 high-demand tech products
node prisma/seed.js

# Start the Express API Server
npm run dev
```
*Backend API Server will be online at: `http://localhost:5000`*

### 3. Frontend Setup & Launch
```bash
# Navigate to frontend directory
cd ../frontend

# Install dependencies
npm install

# Start Vite Development Server
npm run dev
```
*Frontend Web Application will be live at: `http://localhost:5173`*
